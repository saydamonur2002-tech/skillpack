## Faithfulness and changes

Port of simplify.js (getSqDist, getSqSegDist, simplifyRadialDist, simplifyDPStep, simplifyDouglasPeucker, simplify) at the pinned commit. The recursive DP step is replaced by an explicit stack that emits indices in the identical in-order sequence, avoiding Python recursion limits. Object identity in the radial filter (prevPoint !== point) is replaced by index comparison. Default tolerance 1 and the strict greater-than comparisons are kept. Points are [x, y] arrays instead of {x, y} objects; kept_indices are added.

## Reference values

The tolerance-5 case asserts the literal upstream expected array from test/test.js; single-point and empty cases are upstream literal tests. All other expected outputs (and all kept indices) were generated by executing the pinned upstream simplify.js with Node, not by this Python port. reference/verify_upstream.py reruns that comparison locally.

Frozen references are in tests/references.json; each case has an `origin` that distinguishes literal upstream fixtures from values generated by executing pinned upstream code. No full-upstream-suite claim is made.
