## Faithfulness and changes

Ports isPointInside, getBounds, getCenterOfBounds and getCenter from geolib v2.0.24 (src/geolib.js, the last single-file JavaScript release). Upstream getCenter returns toFixed(6) strings; this port returns the same rounded values as numbers (JavaScript toFixed rounding reproduced with Decimal). Holes and MultiPolygon membership are Skillpack composition on top of the upstream ring test: inside the outer ring and not inside any hole. Sexagesimal strings and object/array coordinate forms are not accepted.

## Reference values

The Dortmund polygon and two test points are copied from upstream tests/geolib.test.js (isPointInside true/false literals). All full outputs were generated by executing pinned upstream src/geolib.js in Node, not this port; supplementary cases are labelled.

Frozen references are in tests/references.json; each case has an `origin` that distinguishes literal upstream fixtures from values generated by executing pinned upstream code. No full-upstream-suite claim is made.
