## Faithfulness and changes

Ports DGTSV forward elimination, its abs(diagonal)>=abs(lower) pivot decision, second-superdiagonal storage and back substitution. Restricts the original NRHS loop to one RHS and returns newly added pivot-decision metadata. The native pinned C translation was executed directly; only the error-handler symbol is stubbed and valid reference cases never invoke it. Full bundled LAPACK BSD license and extra no-patent-reassurance paragraph are preserved.

## Reference values

Fixed reference solutions were generated by executing the exact pinned upstream dgtsv.c on declared deterministic matrices, including initial-zero and repeated-pivot cases. Inputs are generated, not falsely represented as literal upstream tests. Their RHS is also independently formed from known x; dense-LU comparison is supplementary, not an independent native reference.

Frozen references are in tests/references.json. Origins distinguish literal upstream fixtures, native-generated differential values, cross-library analytic formulas and supplementary mathematical properties. No unsupported digit guarantee or full-upstream-suite claim is made.
