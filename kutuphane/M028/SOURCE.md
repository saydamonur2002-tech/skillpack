## Faithfulness and changes

Ports distanceTo, initialBearingTo, finalBearingTo, midpointTo, destinationPoint, crossTrackDistanceTo and equals from latlon-spherical.js plus Dms.wrap90/wrap180/wrap360 from dms.js at the pinned commit, with the same operation order (degrees*PI/180) and JavaScript remainder semantics (math.fmod). NaN bearings are returned as null. The compass label is a Skillpack addition (16 sectors of 22.5 degrees). Text parsing of degree-minute-second strings is not exposed.

## Reference values

All case inputs except the labelled supplementary ones and their rounded expectations (destination, bearings, reverse bearing, NaN for coincident points, midpoint, distance in metres and with radius 3959, cross-track) are copied from upstream test/latlon-spherical-tests.js and asserted at the upstream display precision. Full-precision outputs were generated by executing pinned upstream latlon-spherical.js in Node, not this port.

Frozen references are in tests/references.json; each case has an `origin` that distinguishes literal upstream fixtures from values generated by executing pinned upstream code. No full-upstream-suite claim is made.
