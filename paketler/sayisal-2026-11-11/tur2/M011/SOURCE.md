## Faithfulness and changes

Port of scipy/optimize/Zeros/brentq.c at the pinned commit. Preserves the sequential C swap (new xblk is old xcur), secant/inverse-quadratic acceptance rule and bisection safeguard. Horner polynomial evaluation replaces an arbitrary C callback. Zero-division during attempted interpolation falls back to bisection as C nonfinite arithmetic would. Endpoint iteration count is explicitly zero rather than exposing an uninitialized statistic. Original author credit: Written by Charles Harris; header modifications by Travis Oliphant. Contact-only first lines are not redistributed; legal license notices are intact.
