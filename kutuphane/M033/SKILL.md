# Nearby places: nearest-N and within-radius search by category

List places from a local places dataset around a centre point, nearest first (WGS-84 ellipsoidal distance in whole metres), optionally limited to a radius, categories (Turkish or English words such as eczane, kafe, banka, iskele) and a name fragment; or count which categories exist around a point. Answers "bu noktaya 1 km içindeki eczaneler" and "en yakın 3 kafe".

## When and how to use

For "nearest open pharmacy" style questions, say clearly that opening hours are not checked. Pass result.features to M034 to draw them, and optionally rank them by road time with M031. Use only this bounded deterministic operation. Read manifest.json for the exact schema; do not guess missing data, coerce strings/booleans or invent reference values.

Exactly one JSON object is read from stdin; one JSON result is written to stdout. Success: `{ "ok": true, "result": {...} }`. Failure: `{ "ok": false, "error": {"code": "...", "message": "..."} }`, exit status 2. Duplicate keys, nonfinite values, extra properties and oversized input are rejected.

## Map data

This pack reads local map files only. Datasets are chosen by **name**, never by path, inside one folder picked by the human: the `SKILLPACK_MAP_DATA` environment variable, or a `map_data` folder next to the pack. A bare name such as `demo_kadikoy` resolves to `demo_kadikoy_<layer>.geojson` (layers: roads, places, areas), then `.csv`, then `demo_kadikoy.osm`; a name with an extension is used as the file name. Accepted formats: GeoJSON (LineString roads with OSM-style `highway`, `oneway`, `maxspeed`, `name`, `access` properties; Point places with `name` and `category`), CSV places (`name,category,lat,lon`), or a small OSM XML extract (`.osm`, parsed on every call, so keep it small). Files above 64 MiB are refused. The demo dataset is OpenStreetMap data under ODbL 1.0 (© OpenStreetMap contributors) and ships separately from the code; tests use a synthetic CC0 grid in tests/fixtures.

## Scope and failure

Straight-line distance on the WGS-84 ellipsoid (Vincenty, rounded to whole metres as upstream orderByDistance does), not walking or driving distance; use M031 matrix for road times. The radius test is inclusive (distance <= radius_m). Category words are mapped through a small fixed Turkish/English alias table (shown in categories_used); unknown words are matched literally against the dataset category. Opening hours are copied from the data and never evaluated, so "open now" questions cannot be answered. Results depend entirely on what the local dataset contains.

## Faithfulness

Ports geolib v2.0.24 getDistance (Vincenty inverse with toFixed(precision) then Math.round, elevation ignored, NaN for non-convergence turned into an error) and orderByDistance (distance per place, stable ascending sort). With default accuracy 1 and precision 0 distances are whole metres; ties keep dataset order. Filtering by radius, categories, name and the alias table are Skillpack rules. Note: geolib getRhumbLineBearing/getBearing are deliberately not used (their source comment cites GPL-licensed material).
