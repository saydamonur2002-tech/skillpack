# Reproducible upstream reference check

Run `python3 reference/verify_upstream.py` from this pack. It performs no network reads and never imports the Python port in tool/. Instead Node.js runs the included pinned upstream JavaScript file through reference/upstream_harness.js, feeds every input from tests/references.json and compares each output field exactly (absolute tolerance 0) with the frozen expected_subset.

Requires Node.js on PATH; tested with Node v24 on Linux. This is a differential rerun of the pinned upstream code, not the complete upstream test suite.

## Sources and fixture interpretation

Every case input comes from upstream test/polyline.test.js; eleven assert literal upstream expected strings or arrays. Full outputs, including the identity-test inputs, were generated by executing the pinned upstream src/polyline.js in Node, not this port; one supplementary decode is labelled. reference/verify_upstream.py reruns upstream locally.

The exact commit and file SHA-256 values are in manifest.json and SOURCE.md. All legal notices must accompany source redistribution.
