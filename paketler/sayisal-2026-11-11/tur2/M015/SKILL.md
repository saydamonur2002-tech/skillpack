# Cephes regularized incomplete beta with symmetry and dual fractions

Evaluate I_x(a,b), the regularized incomplete beta integral, using the classic 1995 Cephes power series, two continued-fraction forms and reflection. Shape parameters are positive and x lies in [0,1].

## Scope and failure

Double precision, a,b in [1e-4,1000]. Not an inverse beta, incomplete unnormalized beta, beta parameter fit or statistical decision engine. Extreme-tail underflow, legacy complement saturation at 1-MACHEP and relative accuracy degradation near 0/1 remain. Exhausting 300 continued-fraction iterations is now an explicit error rather than an unmarked approximation.

## Faithfulness

Preserves the C expansion-selection inequality, symmetry, both eight-coefficient continued-fraction recurrences, rescaling, small-b*x power series and log-domain path. Uses math.lgamma to implement beta/lbeta instead of porting the separate Cephes gamma family. This is a documented kernel substitution, so no bit-for-bit full-library claim. Carries the historical SciPy root BSD license, original Cephes source copyright, and the explicit author-permitted Cephes BSD license excerpt pinned from v1.14.1.
