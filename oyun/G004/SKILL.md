# 2D collision detection and push-out vector (SAT.js: circles, boxes, convex polygons)

Tests whether two 2D shapes overlap (circle, axis-aligned box, convex polygon with rotation) using the separating axis theorem from SAT.js, and returns the minimum overlap, its direction and the vector that pushes shape A out of B. Used for car-vs-building, car-vs-car and car-vs-pedestrian hits.

MCP server name: `carpisma-testi`; tool: `skillpack_g004`.

## When and how to use

Send up to 500 pairs {a, b}. Box x,y is its corner (minimum x and y), circle x,y is its centre, polygon points are relative to x,y, convex and counter-clockwise with y up (same as SAT.js). If collides is true, move A by push_a to separate it.

Read manifest.json for the exact schema; do not guess missing data, coerce types or invent values. Exactly one JSON object is read from stdin; one JSON result is written to stdout. Success: `{ "ok": true, "result": {...} }`. Failure: `{ "ok": false, "error": {"code": "...", "message": "..."} }`, exit status 2.

## Scope and failure

Convex shapes only; concave polygons must be split. No continuous (swept) collision: very fast objects can tunnel through thin walls in one step. Circle offsets and polygon offsets of SAT.js are not exposed. Results are for one moment; the game decides what a hit means.

## Faithfulness

Port of SAT.js test functions with Vector math inlined. Response.clear() defaults (aInB=bInA=true, overlap=Number.MAX_VALUE) kept. Box is converted by Box.toPolygon. Polygon setPoints duplicate-point removal and setAngle rotation kept. Skillpack additions: input validation rejects clockwise, degenerate or concave polygons (SAT.js silently gives wrong answers there) and push_a = -overlapV.
