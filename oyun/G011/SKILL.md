# Procedural sound effects with ZzFX (horn, crash, siren, pickup, cash, mission, wasted, engine)

Synthesises a sound effect from the 21 ZzFX parameters exactly as ZzFX buildSamples does (with randomness off so the result is repeatable) and reports length, peak, RMS, sample checks and a ready zzfx(...) call. Includes eight game presets; no audio files are needed because the browser regenerates each sound from its parameters.

MCP server name: `ses-efekti`; tool: `skillpack_g011`.

## When and how to use

operation=build with a preset name or a params array (ZzFX order: volume, randomness, frequency, attack, sustain, release, shape, shapeCurve, slide, deltaSlide, pitchJump, pitchJumpTime, repeatTime, noise, modulation, bitCrush, delay, sustainVolume, decay, tremolo, filter; null = default). operation=bank returns the parameter arrays for several presets at once for the HTML builder.

Read manifest.json for the exact schema; do not guess missing data, coerce types or invent values. Exactly one JSON object is read from stdin; one JSON result is written to stdout. Success: `{ "ok": true, "result": {...} }`. Failure: `{ "ok": false, "error": {"code": "...", "message": "..."} }`, exit status 2.

## Place in the game-building flow

Step 8 (sesler): pick one sound per game event (horn, crash, siren, pickup, cash, mission_complete, wasted), check none clips (peak <= 1) and is longer than intended, then pass the parameter bank to G012. The HTML embeds ZzFXMicro (MIT) and plays zzfx(...params) on the event.

## Scope and failure

Randomness is forced to 0 for synthesis; the browser applies the stored randomness when playing, so live sounds vary slightly. Sounds are capped at 5 seconds. The browser plays ZzFXMicro, which multiplies by its master volume 0.3 and keeps samples in a plain array, so live samples differ from these Float32 values by tiny rounding in the delay path. Whether a sound is pleasant is a human judgement.

## Faithfulness

Line-by-line port of ZZFX.buildSamples(v1.4.0) with JavaScript semantics reproduced: % as fmod, Math.round as floor(x+0.5), x|0 truncation, ++crush%0 being NaN (always recompute), the Float32Array buffer (Python array('f')) and the left-to-right biquad filter assignment order. Presets are original Skillpack choices except 'wasted', which is the upstream README 'Game Over' example.

## Evidence and human review

Every case was generated by executing the pinned ZzFX.js buildSamples in Node.js with randomness 0 (reference/upstream_harness.mjs). Four cases are the upstream README examples; the int16 checksum of all samples matches exactly.
