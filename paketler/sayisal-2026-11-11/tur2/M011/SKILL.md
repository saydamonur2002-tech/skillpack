# Bracketed polynomial roots with safeguarded Brent interpolation

Find one real root of a continuous polynomial in an explicit sign-changing bracket. Coefficients are in descending degree order; return root, signed residual, iteration count and evaluation count.

Exactly one JSON object is read from stdin; one JSON result is written to stdout. Success: `{ "ok": true, "result": {...} }`. Failure: `{ "ok": false, "error": {"code": "...", "message": "..."} }`, exit status 2. Duplicate keys, nonfinite values, extra properties and oversized input are rejected.

## Scope and failure

Polynomial degree at most 20; no expression evaluation, arbitrary callback, discontinuity support, complex roots, root multiplicity estimate or promise to find every root. A same-sign bracket is rejected. Coefficient scaling and near-multiple roots can limit residual/forward accuracy; the termination test bounds bracket width rather than certifying an exact zero. A zero endpoint is accepted even if the bracket is reversed.

## Faithfulness

Port of scipy/optimize/Zeros/brentq.c at the pinned commit. Preserves the sequential C swap (new xblk is old xcur), secant/inverse-quadratic acceptance rule and bisection safeguard. Horner polynomial evaluation replaces an arbitrary C callback. Zero-division during attempted interpolation falls back to bisection as C nonfinite arithmetic would.
