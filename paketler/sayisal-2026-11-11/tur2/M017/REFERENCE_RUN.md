# Reproducible native C reference check

Run `python3 reference/verify_native.py` from this pack with GCC available. It performs no network reads, compiles only the included pinned upstream C evidence into a temporary shared library, calls it via ctypes, checks every frozen reference and removes the temporary library. Numerical execution does not import the Python technique port.

The exact compiler command is assembled visibly in verify_native.py: gcc -shared -fPIC -O2 -ffp-contract=off, local include paths, source files and -lm. C translation units were executed on the box during mining; this is not the complete upstream test suite.

The pinned generated DGTSV C translation supplies the complete one-RHS solve. Only XERBLA linkage is needed; the shared scalar shim includes an aborting error handler that valid cases never invoke. Native golden solutions are generated inputs, not literal upstream test vectors. Original Fortran was not executed.

## Sources and fixture interpretation

Fixed reference solutions were generated by executing the exact pinned upstream dgtsv.c on declared deterministic matrices, including initial-zero and repeated-pivot cases. Inputs are generated, not falsely represented as literal upstream tests. Their RHS is also independently formed from known x; dense-LU comparison is supplementary, not an independent native reference.
