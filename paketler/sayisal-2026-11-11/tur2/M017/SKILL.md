## Scope and failure

Order 1..512 and one RHS only. This is not the no-pivot Thomas algorithm used inside an earlier spline pack: adjacent pivots can create a second superdiagonal, which is explicitly retained. Singular zero pivots fail. No cyclic corner entries, SPD specialization, refinement, band matrix generalization or conditioning certificate.

## Faithfulness
