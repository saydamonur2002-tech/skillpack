# Polyline simplification with radial pre-filter and Ramer-Douglas-Peucker

Simplify a 2D polyline given as [x, y] points: optional radial-distance pre-filter, then Ramer-Douglas-Peucker with a distance tolerance in the same units. Returns kept points and their original indices.

## When and how to use

Use only this bounded deterministic operation. Read manifest.json for the exact schema; do not guess missing data, coerce strings/booleans or invent reference values.

Exactly one JSON object is read from stdin; one JSON result is written to stdout. Success: `{ "ok": true, "result": {...} }`. Failure: `{ "ok": false, "error": {"code": "...", "message": "..."} }`, exit status 2. Duplicate keys, nonfinite values, extra properties and oversized input are rejected.

## Scope and failure

Planar Cartesian [x, y] only; no geodesic distance, 3D points, topology preservation or self-intersection repair. Tolerance is a perpendicular distance in input units (squared internally). At most 5000 points. Radial pre-filter (default) can give a different result from pure Douglas-Peucker; set highest_quality=true for the pure algorithm. Points with two or fewer entries are returned unchanged.

## Faithfulness

Port of simplify.js (getSqDist, getSqSegDist, simplifyRadialDist, simplifyDPStep, simplifyDouglasPeucker, simplify) at the pinned commit. The recursive DP step is replaced by an explicit stack that emits indices in the identical in-order sequence, avoiding Python recursion limits. Object identity in the radial filter (prevPoint !== point) is replaced by index comparison. Default tolerance 1 and the strict greater-than comparisons are kept. Points are [x, y] arrays instead of {x, y} objects; kept_indices are added.
