# Slippy-map tile math: lon/lat to z/x/y, tile bounds, quadkeys, parent and children

Web-map (XYZ / slippy map) tile arithmetic: which tile z/x/y contains a longitude/latitude, the fractional tile position, a tile bounding box or GeoJSON outline, Bing-style quadkeys both ways, parent, children, siblings, and the smallest tile covering a bounding box. Useful for naming map tiles, cache keys and zoom reasoning; no tiles are downloaded.

## Scope and failure

Spherical (Web) Mercator tiling only, latitude limited to plus/minus 85.05 degrees, zoom 0-28. Tiles are named, not downloaded; there are no tile URLs, imagery or network access. Tile x/y must be below 2^z. Parent and siblings are refused for zoom 0. bbox_to_tile returns the single smallest tile containing the whole box, which can be much larger than the box.

## Faithfulness

Ports tileToBBOX, tileToGeoJSON, tile2lon, tile2lat, pointToTile, pointToTileFraction, getChildren, getParent, getSiblings, tileToQuadkey, quadkeyToTile, bboxToTile and getBboxZoom from index.js at v1.0.1, reproducing JavaScript 32-bit integer semantics of & and >>> in bboxToTile. getParent quirk (!tile[1]%2) is equivalent to integer halving for valid non-negative tiles. hasTile/hasSiblings/tilesEqual are not exposed.
