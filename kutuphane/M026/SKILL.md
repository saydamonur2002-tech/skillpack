# Point-in-polygon, bounding box and centre of a polygon

For a GeoJSON Polygon or MultiPolygon (holes supported): test which of up to 1000 points are inside (ray casting), return the bounding box, or the centre of the bounds and the mean-vector centre. Answers "is this point inside this area?" and "where is the middle of this area?".

## When and how to use

Use only this bounded deterministic operation. Read manifest.json for the exact schema; do not guess missing data, coerce strings/booleans or invent reference values.

Exactly one JSON object is read from stdin; one JSON result is written to stdout. Success: `{ "ok": true, "result": {...} }`. Failure: `{ "ok": false, "error": {"code": "...", "message": "..."} }`, exit status 2. Duplicate keys, nonfinite values, extra properties and oversized input are rejected.

## Scope and failure

Planar ray casting on raw longitude/latitude numbers: no geodesic edges, no antimeridian handling, and points exactly on an edge or vertex may be reported either way (upstream behaviour). Rings must be in a consistent order; GeoJSON closing positions are dropped before testing. Up to 1000 points and 100 rings of 5000 positions per call. Elevation values are ignored. Bounding box and centres use only outer rings.

## Faithfulness

Ports isPointInside, getBounds, getCenterOfBounds and getCenter from geolib v2.0.24 (src/geolib.js, the last single-file JavaScript release). Upstream getCenter returns toFixed(6) strings; this port returns the same rounded values as numbers (JavaScript toFixed rounding reproduced with Decimal). Holes and MultiPolygon membership are Skillpack composition on top of the upstream ring test: inside the outer ring and not inside any hole. Sexagesimal strings and object/array coordinate forms are not accepted.
