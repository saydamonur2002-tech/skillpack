# Reproducible upstream reference check

Run `python3 reference/verify_upstream.py` from this pack. It performs no network reads and never imports the ported formula or search in tool/main.py. Instead Node.js runs the included pinned upstream JavaScript through reference/upstream_harness.mjs, feeds every input from tests/references.json and compares each output field exactly (absolute tolerance 0) with the frozen expected_subset. The pack tests compare the Python port with the same values using the per-case tolerance stored in references.json.

Requires Node.js on PATH; tested with Node v24 on Linux. This is a differential rerun of the pinned upstream code, not the complete upstream test suite.

## Sources and fixture interpretation

All case inputs except the labelled supplementary ones and their rounded expectations (destination, bearings, reverse bearing, NaN for coincident points, midpoint, distance in metres and with radius 3959, cross-track) are copied from upstream test/latlon-spherical-tests.js and asserted at the upstream display precision. Full-precision outputs were generated by executing pinned upstream latlon-spherical.js in Node, not this port.
