# Reproducible native C reference check

Run `python3 reference/verify_native.py` from this pack with GCC available. It performs no network reads, compiles only the included pinned upstream C evidence into a temporary shared library, calls it via ctypes, checks every frozen reference and removes the temporary library. Numerical execution does not import the Python technique port.

The exact compiler command is assembled visibly in verify_native.py: gcc -shared -fPIC -O2 -ffp-contract=off, local include paths, source files and -lm. C translation units were executed on the box during mining; this is not the complete upstream test suite.

The pinned generated DGETF2 C translation supplies factors/pivots; a small generated scalar BLAS shim provides IDAMAX, DSCAL, DSWAP, DGER and DBL_MIN. The final triangular solve is an explicitly derived harness step, not an upstream DGESV golden fixture. The original Fortran binary was not executed.

## Sources and fixture interpretation

The available upstream DGESV example uses rand() and has no fixed golden outputs, so none are falsely attributed to it. Frozen factors/pivots were generated by compiling the exact pinned upstream DGETF2 C translation with an explicit small scalar BLAS/platform shim. Triangular solutions are derived from those native factors; separate known-solution and reconstruction properties verify the wrapper. Original Fortran was not compiled.
