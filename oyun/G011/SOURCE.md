# Source and changes: Procedural sound effects with ZzFX (horn, crash, siren, pickup, cash, mission, wasted, engine)

Upstream: https://github.com/KilledByAPixel/ZzFX at commit `ac5a4727a44e5506a12f7340087e0b889cfd69dc` (1.4.0), license MIT.

## What was taken

ZZFX.buildSamples synthesis (oscillator shapes, envelope, slide, pitch jump, repeat, noise, modulation, bit crush, delay, tremolo, biquad filter) and README example sounds

## Port notes

Line-by-line port of ZZFX.buildSamples(v1.4.0) with JavaScript semantics reproduced: % as fmod, Math.round as floor(x+0.5), x|0 truncation, ++crush%0 being NaN (always recompute), the Float32Array buffer (Python array('f')) and the left-to-right biquad filter assignment order. Presets are original Skillpack choices except 'wasted', which is the upstream README 'Game Over' example.

## Reference values

Every case was generated by executing the pinned ZzFX.js buildSamples in Node.js with randomness 0 (reference/upstream_harness.mjs). Four cases are the upstream README examples; the int16 checksum of all samples matches exactly.
