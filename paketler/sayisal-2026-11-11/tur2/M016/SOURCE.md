## Faithfulness and changes

Ports the unblocked DGETF2 pivot choice, whole-row swaps, multipliers and rank-one trailing update from the bundled LAPACK Fortran, with its generated C translation as native verification source. Element-wise division avoids reciprocal overflow for subnormal pivots, matching the source safe-minimum fallback. A conventional pivot application and forward/back substitution wrapper is added for one RHS. This does not port blocked DGETRF or optimized BLAS. The selected subdirectory LAPACK BSD license, including its patent-reassurance disclaimer, controls these files and is preserved in full.

## Reference values

The available upstream DGESV example uses rand() and has no fixed golden outputs, so none are falsely attributed to it. Frozen factors/pivots were generated by compiling the exact pinned upstream DGETF2 C translation with an explicit small scalar BLAS/platform shim. Triangular solutions are derived from those native factors; separate known-solution and reconstruction properties verify the wrapper. Original Fortran was not compiled.

Frozen references are in tests/references.json. Origins distinguish literal upstream fixtures, native-generated differential values, cross-library analytic formulas and supplementary mathematical properties. No unsupported digit guarantee or full-upstream-suite claim is made.
