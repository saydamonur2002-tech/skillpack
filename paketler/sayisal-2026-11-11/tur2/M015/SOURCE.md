## Faithfulness and changes

Preserves the C expansion-selection inequality, symmetry, both eight-coefficient continued-fraction recurrences, rescaling, small-b*x power series and log-domain path. Uses math.lgamma to implement beta/lbeta instead of porting the separate Cephes gamma family. This is a documented kernel substitution, so no bit-for-bit full-library claim. Carries the historical SciPy root BSD license, original Cephes source copyright, and the explicit author-permitted Cephes BSD license excerpt pinned from v1.14.1.
