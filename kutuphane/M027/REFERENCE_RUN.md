# Reproducible upstream reference check

Run `python3 reference/verify_upstream.py` from this pack. It performs no network reads and never imports the ported formula or search in tool/main.py. Instead Node.js runs the included pinned upstream JavaScript through reference/upstream_harness.js, feeds every input from tests/references.json and compares each output field exactly (absolute tolerance 0) with the frozen expected_subset. The pack tests compare the Python port with the same values using the per-case tolerance stored in references.json.

Requires Node.js on PATH; tested with Node v24 on Linux. This is a differential rerun of the pinned upstream code, not the complete upstream test suite.

Upstream index.js requires the npm package wgs84 for one constant; the harness supplies RADIUS = 6378137 (the value published by that package) through a require shim instead of downloading it.

## Sources and fixture interpretation

Illinois and whole-world geometries and the point, linestring, rotated-ring, unclosed-ring and degenerate-ring cases are from upstream test/; their literal expectations are asserted to 12 significant digits as upstream does. All full outputs were generated by executing pinned upstream index.js in Node, not this port; supplementary cases are labelled.

The exact commit and file SHA-256 values are in manifest.json and SOURCE.md. All legal notices must accompany source redistribution.
