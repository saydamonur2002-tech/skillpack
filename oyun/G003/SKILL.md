# 2D vehicle kinematics (kinematic bicycle model: accelerate, brake, steer)

Steps a top-down car with the kinematic bicycle model used in PythonRobotics: position from speed and heading, heading from speed, wheelbase and clipped steering angle, speed from acceleration. Answers "how far and where does the car go with this throttle/steer sequence?" and fixes the car parameters the game uses.

MCP server name: `arac-fizigi`; tool: `skillpack_g003`.

## When and how to use

Give the start state (x, y in metres or tiles, yaw in radians, v in units/s), optional params and a list of controls (acceleration, steer_deg, repeat). Use it once while building the game to choose wheelbase, steering limit, acceleration and top speed, and to prove the car can turn inside a road tile. The real-time game runs the same formula in JavaScript; this tool is the reference.

Read manifest.json for the exact schema; do not guess missing data, coerce types or invent values. Exactly one JSON object is read from stdin; one JSON result is written to stdout. Success: `{ "ok": true, "result": {...} }`. Failure: `{ "ok": false, "error": {"code": "...", "message": "..."} }`, exit status 2.

## Place in the game-building flow

Step 3 (araç ayarı): test-drive the player car with the chosen parameters; the final params and speed_limits go to the HTML builder (G012). The JavaScript runtime in G012 implements this exact update and the end-to-end test compares the two.

## Scope and failure

Kinematic model only: no tyre slip, drift, mass, friction or collisions (see G004). Speed clamp (speed_limits) is a Skillpack addition applied after the upstream update. At most 5000 steps per call. Units are whatever the caller uses consistently (the game uses tiles of 1 unit).

## Faithfulness

Direct port of State.update(acceleration, delta) from PathTracking/stanley_control/stanley_control.py with module globals L, dt and max_steer made parameters, and utils/angle.py angle_mod(x) with zero_2_2pi=False, degree=False as (x+pi)%(2pi)-pi. numpy scalar ops replaced by math. steer_deg is converted with radians() like np.radians. Distance and max speed are Skillpack summaries.
